# hch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bun CLI `hch` with `where`, `version` and `up` subcommands that replace the zsh functions `hcw`, `hcv` and `hcup`.

**Architecture:** `src/cli.ts` dispatches subcommands. `src/hc.ts` wraps the `hc` CLI with Bun Shell and exposes typed results. Each command is a file in `src/commands/` with its pure formatting/argument-building split into exported functions that `bun test` covers; the parts that touch live processes are verified by running `hch` in a herdr terminal.

**Tech Stack:** Bun 1.4.2, TypeScript, Bun Shell (`$` from `"bun"`), `util.parseArgs`, `bun test`. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-17-hch-design.md`

## Global Constraints

- No runtime dependencies.
- Reads `HC_TERMINAL_ID`; when unset, print `hch: not in an hc terminal` to stderr and exit 1.
- Output matches the zsh functions in the user's zsh config.
- `hc` version strings look like `hc 0.1.21`; the version is the second space-separated field.

## Review Focus

- `HC_TERMINAL_ID` unset → one-line error, exit 1, no stack trace (Task 1 test on `requireTerminalId`).
- Terminal has no `where` label or no `herdr.*` labels → `where` prints `?` / empty instead of throwing (Task 1 test).
- `hc` fails (non-zero exit) → print `hch: ` + hc's stderr, exit with hc's code, no stack trace (Task 1, `main` catches `ShellError`).
- `hch up` when `hc run` returns no address → must not kill the old terminal (Task 3 test on `parseRunAddress`).
- Unknown subcommand → usage to stderr, exit 2 (Task 1 manual check).

### Task 1: Scaffold, hc wrapper, CLI dispatch and `hch where`

**Files:**
- Delete: `index.ts`
- Modify: `package.json` (add `"bin": { "hch": "./src/cli.ts" }`, `"scripts": { "test": "bun test" }`, drop `"module"`)
- Create: `src/hc.ts`, `src/cli.ts`, `src/commands/where.ts`
- Test: `src/commands/where.test.ts`

**Interfaces:**
- Produces in `src/hc.ts`:
  - `type Terminal = { address: string; pid: number; cwd: string; labels: Record<string, string> }` (other fields ignored)
  - `requireTerminalId(env?: Record<string, string | undefined>): string` — throws `HchError("not in an hc terminal")` when unset
  - `class HchError extends Error { exitCode: number }` (default 1)
  - `getTerminal(id: string): Promise<Terminal>` — `` $`hc get ${id} --json`.json() ``
- Produces in `src/commands/where.ts`: `formatWhere(t: Terminal): string`, `where(): Promise<void>`
- `src/cli.ts`: shebang `#!/usr/bin/env bun`; subcommands `where`, `version`, `up`, `help`; no args / `help` / `--help` / `-h` print usage to stdout exit 0; unknown → usage to stderr, exit 2. Catches `HchError` (print `hch: <message>`, exit `exitCode`) and Bun `ShellError` (print `hch: ` + trimmed stderr, exit its `exitCode`).

- [ ] **Step 1: Write the failing tests** in `src/commands/where.test.ts`:

### Task 2: `hch version`

**Files:**
- Create: `src/commands/version.ts`
- Test: `src/commands/version.test.ts`

**Interfaces:**
- Consumes: `requireTerminalId`, `getTerminal` from `src/hc.ts`
- Produces: `parseVersion(output: string): string` (second space-separated field of the first line, trimmed; throws `HchError` if missing), `formatVersion(tab: string, installed: string): string` → `"tab: <tab>  installed: <installed>"`, `version(): Promise<void>`

- [ ] **Step 1: Write the failing tests:** `parseVersion("hc 0.1.21\n")` → `"0.1.21"`; `parseVersion("")` throws; `formatVersion("0.1.20", "0.1.21")` → `"tab: 0.1.20  installed: 0.1.21"`.
- [ ] **Step 2:** `bun test` → FAIL.
- [ ] **Step 3:** Implement. Holder pid = `ps -o ppid= -p <terminal.pid>` trimmed; holder executable = first `n`-prefixed line of `lsof -a -p <holder> -d txt -Fn` with `n` stripped; tab version = `parseVersion(await $`${exe} --version`.text())`; installed = `parseVersion` of `~/.local/bin/herdr-core --version` (resolve `~` via `os.homedir()`). Wire into `cli.ts`.
- [ ] **Step 4:** `bun test` → PASS; `hch version` output equals `hcv` output in the same terminal.
- [ ] **Step 5: Commit:** `feat: add hch version`

### Task 3: `hch up`

**Files:**
- Create: `src/commands/up.ts`
- Test: `src/commands/up.test.ts`

**Interfaces:**
- Consumes: `requireTerminalId`, `getTerminal`, `HchError` from `src/hc.ts`
- Produces in `src/hc.ts`: `runTerminal(args: string[]): Promise<unknown>` (runs `hc run --bg --no-parent --keep --json ...args`, returns parsed JSON), `killTerminal(id: string): Promise<void>` (stdout quiet)
- Produces in `src/commands/up.ts`: `labelArgs(labels: Record<string, string>): string[]` (one `--label=k=v` per label except `herdr.seen`), `parseRunAddress(json: unknown): string` (returns `.address`; throws `HchError("couldn't start the new terminal")` when missing/null/empty), `up(): Promise<void>`

- [ ] **Step 1: Write the failing tests:** `labelArgs({ "herdr.seen": "1", where: "a / 1", "herdr.tab": "tb" })` → `["--label=where=a / 1", "--label=herdr.tab=tb"]`; `labelArgs({})` → `[]`; `parseRunAddress({ address: "t20" })` → `"t20"`; `parseRunAddress({})`, `parseRunAddress({ address: null })`, `parseRunAddress(null)` each throw `"couldn't start the new terminal"`.
- [ ] **Step 2:** `bun test` → FAIL.
- [ ] **Step 3:** Implement `up`: get terminal, `runTerminal(["--cwd", process.cwd(), ...labelArgs(t.labels)])`, `parseRunAddress`, print `hch up: <old> -> <new>`, then `killTerminal(old)`. Kill only after a valid address. Wire into `cli.ts`.
- [ ] **Step 4:** `bun test` → PASS. Manual (the user runs it, since it kills the terminal): in a spare herdr tab, `hch up` → new shell appears in the same tab and cwd; `hch where` there shows the same space and tab.
- [ ] **Step 5: Commit:** `feat: add hch up`
- [ ] **Step 6:** Ask the user before removing `hcw`, `hcv`, `hcup` from the user's zsh config.
